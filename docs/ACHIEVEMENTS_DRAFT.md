# まなびバトル アチーブメント たたき台

## ごほうびの種類
- **称号**：対戦・ボス戦のキャラ紹介で、名前の上に出る。ホームで1つ選んでつける
- **オーラ**：キャラのまわりのエフェクト。**銀・金・虹の3種類**。ホームで1つ選ぶ
- **背景**：ホーム画面（部室）の背景。ホームで1つ選ぶ

## 方針
- 負けないと取れないもの、復習しないと取れないものは入れない（かしこい子も、そうでない子も取れる）
- 対戦の勝ち数は入れない（対戦の結果はセーブしないため）
- 「1日に○問」のような、やりすぎをすすめるものは入れない
- 「遊んだ日数」は連続ではなく合計
