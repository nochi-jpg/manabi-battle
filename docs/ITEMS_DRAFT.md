# manabi-2 アイテム たたき台（v3）

## ルール
- **上位互換を作らない**。どのアイテムにも得意・苦手な場面と「対策」がある
- **レア度（★1〜★5）は強さではなく、クセの強さ**
- **すべて永続**（消耗品なし）。ただし「対戦中1回だけ発動」はある
- **同じアイテムは1つだけ**。持っているアイテムはダンジョンでもガチャでも出ない（＝コレクション）
- **対戦に持ちこめるのは4つ**
- **ダンジョンには持ちこまない**。そのダンジョンで拾ったアイテムだけ、その回のダンジョン（道中・ボス戦）で効く
- ダンジョン中は4個まで（5個目でその場で1つ捨てる）。リザルトで未取得のものから1個だけ持ち帰る
- **全70個**（★1:12／★2:18／★3:17／★4:13／★5:10）
- ガチャは全部そろったら「コンプリート！」で終わり
- **コンボの片方しかない対策**：①どのパーツも単体で役に立つ（増幅パーツにも小さな発動確率をつける） ②説明に「相性のいいアイテム」を表示 ③**出現条件**：増幅パーツは、もとになるアイテム（またはスキル）を持っていないとダンジョンにもガチャにも出ない
