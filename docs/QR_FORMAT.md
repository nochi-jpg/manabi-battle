# セーブQRの中身（形式 1）

続編でも同じQRで引きつげるように、形式をここに書いておく。作り方・読み方は `savecode.js`。
**項目は後ろに足すだけ**（順番を変えない・消さない）。形式を変えたら先頭の形式番号を上げる。

- QRは Byte モード・誤り訂正 L。中身はバイト列（2500問で約650〜950バイト。解いた問題がふえるほど大きくなる）
- 数 = 可変長の整数（7ビットずつ・続きがあれば最上位ビット1）
- 文字 = UTF-8 の長さ（数）＋本体
- ビット列 = 8個ずつ1バイトに（下のビットから）

| 順 | 項目 | 形 |
|---|---|---|
| 1 | 目印 `M` `B` | 2バイト |
| 2 | 形式番号（今は 1） | 1バイト |
| 3 | プレイヤーネーム、キャラネーム | 文字×2 |
| 4 | 5教科のステータス（国語・算数・理科・社会・英語） | 数×5 |
| 5 | タイプ（0=全教科、1〜5=教科） | 1バイト |
| 6 | コイン、スタミナ、日付（2020-01-01からの日数）、きょう持ち帰った数、塔のきょうの秒数 | 数・数・数・1バイト・数 |
| 7 | 最後のボス（0=なし、1〜6=国語・算数・理科・社会・英語・無） | 1バイト |
| 8 | ダンジョン回数、クリア回数、ノーコンティニュー勝ち、遊んだ日数、ガチャ回数 | 数×5 |
| 9 | フラグ（1ビット目=タイプが変わったことがある） | 1バイト |
| 10 | 倒したボスの属性、3段階目を倒した属性 | 6ビット×2 |
| 11 | 塔の最高到達階（5教科） | 数×5 |
| 12 | アイテム数 N、持っているアイテム、おきにいり（`data.js` の並び順） | 数・Nビット・Nビット |
| 13 | アチーブメント数 M、達成したもの（`data.js` の並び順） | 数・Mビット |
| 14 | 称号（そのごほうびのアチーブメント番号＋1。0=なし）、オーラ（0=オフ、1=銀、2=金、3=虹）、背景（`DATA.BGS` の並び順） | 1バイト×3 |
| 15 | 問題数 Q、問題の状態（番号1〜Q。0=まだ、1=復習まち、2=あと1回、3=卒業） | 数・2ビット×Q |
| 16 | 一発で正解できなかったか（「あと1回」「卒業」の問題だけ、番号の小さい順。「復習まち」は必ずまちがえているので書かない。先生用ページの正答率に使う） | その問題数ぶんのビット |
| 17 | チェック用の数字（FNV-1a 32bit。「カギ＋1〜16＋カギ」から作る） | 4バイト |

- QRに入れないもの：ダンジョンのとちゅう、塔のとちゅう（引きついだら塔は1階から）、問題ごとの「きょう上がった日」
- チェック用の数字が合わないQRは読まない（書きかえ防止）。ただしカギはコードの中にあるので、くわしい人なら作れてしまう（サーバーがないため防げない）
