# セーブQRの中身（形式 3。2026-10-13 配布版で 確定）

作り方・読み方は `savecode.js`。**これから 項目は 後ろに 足すだけ**（順番を 変えない・消さない）。形式を 変えたら 形式番号を 上げる。
形式2までの QR は 読まない（ver 1.15 で アイテムの 並びが 変わったため。「前のバージョンのQRなので 読めないよ」）。

- QRは Byte モード・誤り訂正 L。大きさの めやす：はじめ 約170バイト・半分 解いて 約450〜700バイト・ぜんぶ 解いて 約420〜850バイト
- 数 = 可変長の整数（7ビットずつ・続きがあれば最上位ビット1）
- 文字 = UTF-8 の長さ（数）＋本体
- ビット列 = 8個ずつ1バイトに（下のビットから）

## 問題の 圧縮（16）
- LZMA と 同じ 2進の レンジコーダー（確率 11ビット・更新 5ビット）。1問を 2ビット（上の ビット → 下の ビット）で 書く
- 確率は 「ひとつ前の 問題の 状態（4とおり）」ごとに 3つ（上の ビット・下の ビット×2）。はじめは ぜんぶ 1/2（1024）
- おわりに 5バイト 書き出す（LZMA の flush）。`rcEncode`・`rcDecode`

## QRに 入れないもの
- ダンジョン・塔の とちゅう、「あと1回」に なった日（引きついだら 次の日を またずに 復習に 出る）
- 一発で 正解できなかったか（10/13 に なくした。先生用ページの 正答率は「いま 復習まちで ない 割合」）
- 音量・はやさ・もちもの画面の 並びかえなどの 設定、見た 状態異常の 説明、チュートリアルの すすみ

- チェック用の数字が合わないQRは読まない（書きかえ防止）。ただしカギはコードの中にあるので、くわしい人なら作れてしまう（サーバーがないため防げない）

## 問題の番号が変わったとき
- `tools/renumber_questions.py` で番号をそろえなおすと、問題DBの版が上がり、`qmap.js` に「前の番号→新しい番号」の対応表が足される
- 古いセーブ・古いQR・先生用ページの記録は、読みこむときに対応表で新しい番号に直す
