## 1. 動作環境・配信
- ファイルを開くだけで動く（サーバー不要・fetch不使用・JSは script タグで読む）
- Teams で ZIP 配信。子どもは「ダウンロード→展開→Edgeで開く」（Teamsのプレビューでは開かない）
- GitHub Pages でも公開（nochi-jpg/manabi-battle）
- 1人1台。毎日少しずつ遊ぶ想定（育成は1日10分程度）
- 画面 1280×720 固定（前作と同じ）。画像がなくても絵文字で動く
- **グラフィックは著作権フリー素材を使う**（AI生成の画像は使わない。前作の画像も流用しない）
  - ①〜②は絵文字とグラデーションのみで作る
  - ③で使う素材は、利用規約（商用・教育利用、ZIPでの配布、公開リポジトリに置くことが「素材の再配布」にあたらないか、クレジット表記）を確認し、`CREDITS.md` に出典とライセンスを記録する

## 2. セーブ
- ブラウザに自動保存（localStorage、保存名は `manabi_battle_` で始める。前作と同じ GitHub Pages の場所なので混ざらないように）。1人1スロット
- 「そのPC・そのブラウザ」ごとに別のセーブ。GitHub版とZIP版も別（QRで移せる）。シークレットウィンドウでは閉じると消える
- **1問ごとに自動セーブ**。ブラウザを閉じても、開きなおせば続きから
  - 育成ダンジョン：何問目・持ち物・イベントの結果まで。問題・ドロップ・イベントは入ったときに先に決めておき、開きなおしても同じ結果（やり直しでねらえない）
  - CPUボス戦・無限の塔：答えを押した瞬間にセーブ（まちがえてから閉じても取り消せない）
  - 無限の塔：ホームにもどっても続きから（いつでも中断できる）
  - 対戦：途中から再開できる（チャイム対策）。対戦モードを開くと「続きから／新しく」を選ぶ。結果はセーブに残さない
- セーブに版番号を入れ、新しいZIPに差しかえても引きつげるようにする
- せってい画面で **QRコード** に出力（全部入り）。カメラで読みこんで復活できる
- QRにチェック用の数字を入れ、書きかえたQRは読めないようにする
- 中身：ゲームの進み具合・ステータス・持ち物・スキル ＋ 全問題の正誤情報（2500問で約500〜650バイト）

## 3. 問題と学習記録
- questions.js を流用（保健150問は除く → 1034問）。HANDOFF.md の問題づくりのルールを守る
- 各問題に番号をつける。番号は 教科（国語→算数→理科→社会→英語）→学年 の順の通し番号。問題を足したら番号をそろえなおし、古い番号は対応表（qmap.js）で引きつぐ
- 問題ごとに記録：まだ／正解／まちがい（＋復習の段階）
- 選択肢は毎回シャッフル

### 出題の範囲（学年）（2026-10-07 変更）
- **せってい → 📚 出題範囲** で、教科ごとに **4年・5年・6年** を えらぶ（さいしょは 全教科 4年）。QRにも入る

- 3学年とも 解き終わったら **おさらい**
- 解き終わったら **おさらい**：正解ずみの問題がもう一度出る。上がるステータスは少なめ（例：0.3）
- 1日の「新しい問題の数」の上限は設けない（スタミナの制限のみ）

- 速く答えるボーナスは入れない

## 4. 復習のルール（2026-10-01 変更）
4択はたまたま正解することもあるので、**全問 最低2回 正解して卒業** にする。1回正解した問題も復習ダンジョンでもう一度解いて、定着をめざす。

| 問題の状態 | なりかた |
|---|---|
| まだ | まだ解いていない |
| 復習まち | 育成ダンジョンで不正解 |
| あと1回 | 育成ダンジョンで正解／復習まちを復習ダンジョンで正解 |
| 卒業 | あと1回を復習ダンジョンで正解 |

| 場面 | ステータス | コイン |
|---|---|---|
| 育成ダンジョン（道中・ボス戦）で正解（→あと1回） | ＋8 | ＋40 |
| 育成ダンジョン（道中・ボス戦）で不正解（→復習まち） | ＋0 | ＋0 |
| 育成ダンジョン（道中・ボス戦）で 復習まちを正解（→あと1回） | ＋8 | ＋40 |
| 復習ダンジョンで 復習まちを正解（→あと1回） | ＋8 | ＋40 |
| 復習ダンジョンで あと1回を正解（→卒業） | ＋2 | ＋10 |

- 復習ダンジョンに出るのは「復習まち」（いつでも）と「あと1回」（あと1回に なった 次の日から）の問題（2026-10-05 変更：復習まち → あと1回 の 日の しばりは なし）
- 育成ダンジョン（道中・ボス戦）で正解しても **あと1回まで**。卒業は かならず 別の日の 復習ダンジョンで
- まちがえても、ほかの問題をはさんで同じ日に再挑戦できる（状態は下がらない）
- 最終的にもらえる量は、どの道すじでも 1問 ステータス10・コイン50（おさらいは ステータス＋3・コイン＋10）

### 4-3. 本ステータスと 仮ステータス（2026-10-05）
- **本ステータス**：見た目・進化・ホーム・タイプ・対戦・QRゴースト・先生用ページ・まなスタ
- **仮ステータス**：育成ダンジョンに 入ったとき（ボタンを おしてから リザルトまで）の 本ステータスの コピー。道中・ボス戦の 正解で 上がる。見た目は かわらない
  - 中断して ホームに もどっても 本ステータスは かわらない
  - タイプは 入ったときの まま（見た目しだい）
  - ボス戦：最大HPは ボス戦の はじめに 決まる。攻撃力は スキルを えらぶ ときの 仮ステータスで 決まる（そのターンの 正解ぶんは 次のターンから）
- **リザルト**で 上がった分を 本ステータスに 自動で 足す（ふりわけは しない）→ 見た目が かわれば 進化演出
  - 負けて コンティニューしないときも リザルト：ステータス・コインは 足す。ボスの ごほうび・持ち帰りは なし。ランクは「—」（記録しない）
- コインは 正解した しゅんかんに 足す（いままでどおり）
- 本ステータスが かわって 見た目が かわるときは **いつも 進化演出**（リザルト・ボーナスの ふりわけ・デバッグの 数値・QR引きつぎ）。何段階 とんでも 1回（さいごの すがた）

### 主人公

- 攻撃したときのダメージは、その教科のステータス値で決まる

- **1問正解**：その教科＋8 → 復習ダンジョンでもう1回正解＋2（4. 復習のルール）。学年による差はなし。おさらい＋3

- **HP**：5教科の合計×0.7（例：合計500ならHP350）。HP特化ビルドはアイテムでのみ可能
- **ダメージ** ＝ 教科の攻撃力 × 問題ゲージ × スキルの倍率 × 相性 × 会心 × アイテム
  - 教科の攻撃力＝平均 ×（その教科÷平均）^0.8（特化しすぎた教科は伸びが少しゆるやか。特化が強くなりすぎないように）
  - 問題ゲージ：正解で＋1、まちがいで＋0.5、最後に問題数で割る（全問正解1.0、全問まちがいでも0.5は通る）。1問ごとにのびるのが見える
- **ゾンビ戦法（守り・回復・HPで判定勝ちねらい）対策**【案・④で確認】
  - 受けるダメージカットは合計25%まで
  - 最大HPアップは合計+40%まで
  - 決戦ターン（3ターン目だけ特別ルール）は入れない。上限だけで調整する
- **シミュレーターの結果**（tools/sim/。ステータス合計2000・正答率75%・アイテム4個ランダムで数万戦）
  - 決着：3ターン目KO 70%、2ターン目KO 18%、判定 12%
  - アイテムごとの勝率：おおむね45〜58%（極端に強い・弱いものは修正ずみ）
  - かしこさの差：正答率90% vs 60% で 64%勝つ（差はつくが、逆転もある）
  - 育て方：特化 vs バランス 52%
  - アイテム4個 vs 0個：68%
- **保健はなし**（問題もゲームに出さない）
- **すばやさはなし**
- **運**：初期値1000（上限）、下限300。5教科ステータスのばらつき（全体のバランス）で決まる。1問ごとに計算しなおす（算数ばかり解くと下がる。ほかの教科を解けば回復）
  - **運はホーム画面でしか見られない**（正解したのにマイナス表示が出ないように、ダンジョン中は表示しない）
  - 計算：運 = 1000 − 500 ×（ばらつき係数 ÷ 1.6）^1.5（ばらつき係数＝標準偏差÷平均）
  - 試算：算数だけ10問→約890、30問→約720、100問→約500、200問→約410。長く均等に育てた子は、あとから特化してもあまり下がらない（これでよい）

- **会心**：基本10%で威力2倍。会心率＝10%×運÷1000（運800で8%、運300で3%）

## 7. スタミナ
- **ためられる**：毎朝5時に+100。使わなければたまる（5日あけたら500）。**上限2000**（20日分。2026-10-01 変更。1日休んだだけで差がつかないように）。それ以外にふやす方法はない
- 育成ダンジョン1回で50消費（1回5分程度）。毎日なら1日2回
- 復習ダンジョン・問題リスト・対戦などはスタミナなしで遊べる
- ホームの「⚡スタミナ」をタップすると、たまり方の説明が出る

## 8. 育成ダンジョン（1回5分程度）
- **1回19問**：道中10問（ステータスが上がる）＋ボス戦9問（3問×3ターン）
- **道のり**：スタート → 雑魚3体 → イベント → 雑魚2体 → **分かれ道（1回）** → 雑魚3体 → イベント（ないこともある） → 雑魚2体 → **🎁ボス前の宝箱（必ず。3つとも未取得のアイテムから1つ選ぶ）** → ボス
  - 雑魚10体＝10問。どこかでレア雑魚に入れかわることがある
  - 分かれ道は「コインが多そう」「アイテムがありそう」「イベントがありそう」から2つ出る
  - イベントは1〜2回＋ボス前の宝箱。一覧は **docs/EVENTS_DRAFT.md**
  - アイテムは雑魚のドロップ3〜4個＋イベントで、合計6個前後
- 問題を解きながら奥へ進み、最後のボス（CPU戦）を目指す
- **雑魚敵**：攻撃してこない。問題を解くと1撃でたおせる。たおすとステータスが上がる
  - 見た目（モンスターの種類）で落とすアイテムが変わる（ランダム）
  - まちがえたら敵は逃げる：ステータス・アイテムはもらえない。問題は復習まちになる（4. 復習のルール）
  - **レア雑魚**：まなびコインをたくさん落とす。出現率は運で上下する
- **分かれ道**：「コインが多そうな道」などを選べる
- **ランダムイベント**を多数：まなびコインのショップ、メリット・デメリットのあるイベント など
- アイテムは1回のダンジョンで6個前後出る。拾ったアイテムはその回の道中・ボス戦で効く
- ダンジョン中に持てるのは **4個まで**。5個目を拾ったら、その場で1つ捨てる
- すでに持っているアイテムもダンジョンには出る（その回は使える）
- **未取得のアイテムが必ず1つ出るイベント**が毎回ある
- **リザルトで1個だけ持ち帰る**（未取得のものから選ぶ）。ダンジョンからは1日2個まで
- 教科は自由に選べる（特化すると運が下がる）
- ステータス合計が上がるほど、ダンジョンの難易度も上がる

### ボス
- 属性はランダム：国語・算数・理科・社会・英語・無属性。**1日に同じボスが2回連続では出ない**
- ダンジョン開始時に弱点の予告演出
  - 例：「ダンジョンの奥から、熱気を感じる……（このステージのボスは火（国語）属性。水（算数）が有効で、雷（社会）は効きづらいようだ）」
- **ボスのHP（難易度）**：`K.BOSS_HP` で ★1・★2・★3 ごとに倍率。ねらいは ノーコンティニューで アイテムあり全問正解≒90%・アイテムなし正答80%≒50%（`tools/boss_balance.py` ではかる）
- **弱点補正（CPUボス戦のみ）**：育てていない教科でも弱点なら通るようにする
  - 例：「紋章が輝く…！！ このボスには弱点属性の攻撃力が○倍になる」
  - ○倍はその時のステータスに合わせて自動で決め、**特化ステータスの攻撃力と同じくらい**になるようにする（算数特化の子が算数だけ解き続けるしかない、を防ぐ）

### ボスに負けたら
- 負ける＝自分のHPが0、または3ターンで決着せずHPの割合で負ける
- 「コンティニューする？」→ **みんなの応援**
  - 自分のHPは全回復、ボスのHPは減ったまま
  - 仲間（コトハ・ミズナ・ミドリ・ヒカリ（4人の妖精・10/3に変更））が応援にかけつける演出
  - 応援ターン：いつもどおりスキルと教科を選び、3問解いて攻撃。威力が自動で上がり、**全問まちがえても必ず倒せる**（正解するほど演出が派手になる）。ボスは攻撃してこない
  - 1回のコンティニューで必ず終わる
- コンティニューしなくても、ステータスとアイテムはそのまま持ち帰れる（そのままリザルトへ）
- コンティニューしても、ボス撃破報酬のアイテムとまなびコインは100%もらえる
- **ノーコンティニュー**で倒すと、ボス撃破報酬のアイテムのレア度が上がる（ごほうび）

## 11. 無限の塔
- スタミナなし・ステータスは上がらない
- 入るときに **教科を選ぶ**。その教科の問題を解き続ける（1問＝1階）
- 問題はランダムだが、4年 → 5年 → 6年 の順に出る。同じ問題は出ない

- **ハート3つ**（❤️❤️❤️）。3回まちがえたら終了 → 次は1階からやりなおし
- いつでも中断できる（塔の入口にもどっても、ブラウザを閉じても続きから）
- **時間制限**：1日合計10分（2026-10-02 変更。前は30分。毎朝5時にリセット）。塔にいる間だけ画面上に残り時間（10:00:00）が減っていく。0になったら進み具合を自動セーブし、「きょうはここまで！ セーブしたから大丈夫。また明日つづきから登ろう」と表示してからホームにもどる
- 対戦には時間制限なし
- 教科ごとに **最高到達階をセーブに記録**
- **正誤は記録しない**（育成ダンジョンでは「まだ」の扱いのまま。復習ダンジョンにも入らない）
- まなびコイン：正解1問ごとに ＋1（何周目でも同じ）
- **入場券**：塔ごとに1日1回（毎朝5時にもどる。あしたにくりこせない）
  - 入場券で入ると1階から。中断しても、その日も次の日も つづきから再開できる（再開には入場券を使わない）
  - 前の日からのつづきでゲームオーバー → それは前の日の入場券なので、きょうの入場券で もう一度1階から入れる
  - 1日10分の時間制限（全部の塔の合計）
- 問題の窓は閉じずに、同じ窓で次の問題が出る（テンポよく）

## 16. 戦闘（対戦・CPUボス共通）
### 対戦の準備
- 2人のセーブQRを読みこむ（1台の端末で）
- CPUボス戦は ② キャラ紹介から始める（①はなし）
- 対戦の結果はセーブに残さない
- 対戦後は「再戦する」か「タイトルにもどる」を選ぶ

### ① 持ちこみアイテム選択（対戦のみ）
- 「プレイヤーAだけ画面を見てください」→ 自分のアイテム一覧から最大4個を選ぶ
- 「プレイヤーBに画面をわたしてください」→ Bも選ぶ
- 相手の持ち物一覧は見えない

### ② キャラクター紹介（2人で見る）
- A・Bのキャラと持ちこみアイテム、その効果を発表

### ③ 戦闘（2人で見る・最大3ターン）
1. **先攻後攻の決定**：ルーレットで「決める権利」を決める。運が高いほうがルーレットの幅が広い。権利を得たほうが、そのターンの先攻・後攻を選ぶ
2. **スキル・教科の選択**：
   - 先攻がスキル → 教科を選び、その教科の問題を **5問** 解く（**CPUボス戦は3問**）
   - 1問ごとに攻撃力が上がっていくのが見える。まちがえても上がるが、マイナス補正がかかる
   - 出る問題は **その人がすでに解いたことのある問題** から（対戦中の復習。育成をがんばるほど問題が増えて難しくなる）
   - アイテムの補正・特殊効果がかかる
   - 後攻も同じことをする（先攻の選択を見てから選べる）
