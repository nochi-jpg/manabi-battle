# manabi-2 ダンジョンのイベント たたき台（v2）

## 道のり
スタート → 雑魚3体 → **イベント①** → 雑魚2体 → 分かれ道 → 雑魚3体 → **イベント②**（ないこともある） → 雑魚2体 → **🎁ボス前の宝箱（必ず）** → ボス

## ルール
- イベントで出る問題は「解いたことのある問題」から出る。正誤は記録しない（ステータスは上がらない）
- **ステータスの伸び率が変わるイベントは入れない**（対戦に響くため）
- **コインを失うイベントは入れない**（ガチャのために集めているので）。使うかどうか自分で選べるものだけ
- 運が高いと、よい結果が出やすいイベントがある（🍀マーク）
- 前作のキャラ（名前と役割）が仲間としてイベントに登場。画像は著作権フリー素材で新しく用意する
  - ルリ＝お店／ミコト＝おみくじ／ヴァルツ＝取引／ハヤテ＝スカウト／クロガネ＝修行
  - **コトハ＝古い石碑／カズマ＝いやしの泉／ミドリ＝こぼれたコイン／ライト＝なぞの占い師**

## 分かれ道
「コインが多そう」「アイテムがありそう」「イベントがありそう」から2つ出る
- コインが多そう：次の雑魚3体のうち1体がレア雑魚
- アイテムがありそう：次の雑魚3体のうち2体が必ずアイテムを落とす
- イベントがありそう：イベント②が必ず起きる
